# Samples

Run these examples in order to learn the GitHub Copilot SDK:

1. `01_send_your_first_prompt.py` - Send a prompt and print the response.
2. `02_use_conversation_context.py` - Reuse context within a session.
3. `03_build_an_interactive_chat.py` - Build a terminal chat loop.
4. `04_stream_responses_with_events.py` - Stream responses with session events.
5. `05_customize_behavior_with_system_prompts.py` - Customize assistant behavior.
6. `06_add_azure_devops_tools.py` - Add tools for Azure DevOps pull requests.

Run a sample from the repository root:

```powershell
uv run samples\01_send_your_first_prompt.py
```

Copy `.env-template` to `.env` and configure it before running the Azure DevOps sample.
